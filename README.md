# 35024号怪象-Anomaly35024 原创配乐库

Minecraft 伪实况恐怖系列《35024号怪象-Anomaly35024》的原创配乐库，由 **Xlord** 作曲。

# Anomaly35024 OST

An original soundtrack library for the *Minecraft* "pseudo-Let's Play" (found-footage style) horror series *Anomaly35024*, composed by **Xlord**.

These tracks were created for the series itself. The guiding principle is that music should remain absent for the most part, appearing only when the visuals demand it. Any discernible strong beats, predictable structural transitions, or continuous melodic flows are avoided, as they would otherwise distract from the content.

## Directory Structure

```
Music/
├── Audio file/     # Exported final versions: .ogg
├── Source file/    # MuseScore project files: .mscz
└── LICENSE         # Full text of the CC BY-SA 4.0 license
```

- `Audio file/`: Currently contains `.ogg` exports for tracks H01, H02, and H03; other tracks are available only as `.mscz` project files.
- `Source file/`: Contains MuseScore 4 project files (`.mscz`), which can be opened and edited directly using MuseScore.
